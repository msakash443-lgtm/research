## What this run did not cover
- Her topic, her papers, her gold set (X.15): κ and false-exclusion on real data are **not measured**.
- Any real model, any live third-party scholarly API, PostgreSQL.
- X.41 (step-pattern fixes) and X.46.4 (suggestion component) are not built, so M2.11's own prerequisites are not met.

## Mistakes in this run, for the record
- My first note edit left out `base_revision`, so it silently failed (`422`) and the revisions list showed one entry; I only noticed because the list looked wrong. It was re-run correctly above.
- My first stale-work run could not advance the stage because a Recommended exit condition (EC-1.2, no research question) was unmet; it was re-run with a question written, which is what the exit-condition design intends.
